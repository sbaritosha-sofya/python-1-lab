# Учебный корпус для анализа сходства

Корпус полностью синтетический: реальные работы студентов не использовались.
Идентификаторы студентов (`student-s01`, ...) вымышлены. Набор нужен только для
проверки конвейера и сравнения методов, а не для выводов о реальных людях.

## Файлы

- `submissions.jsonl` — сдачи в формате ЛР1, по одной JSON-записи на строку.
- `origins.jsonl` — происхождение каждой сдачи: `family_id`, `variant`, `split`,
  `source_submission_id` (у оригинала `null`).
- `pairs.jsonl` — размеченные пары: `derivation_relation`, `template_only`,
  `family_id`, `assignment_id`.
- `split.json` — какие семейства и отдельные независимые работы относятся к
  настройке (`setup`), а какие к оценке (`eval`).
- `lab-sort.assignment.json`, `lab-counter.assignment.json` — описания заданий.

## Состав

- 33 сдачи, 45 размеченных пар.
- Два задания: `lab-sort` (27 сдач) и `lab-counter` (6 сдач).
- Отношения: `exact_copy`, `reformatted_copy`, `renamed_copy`, `comment_change`,
  `same_template`, `independent`.
- 10 пар с разрешённым шаблоном (`same_template`, `template_only=true`).
- Семейства целиком попадают либо в `setup`, либо в `eval`; производные одной
  работы не оказываются по обе стороны.

## Разделение

`setup`: семейства `sort-a`, `sort-c`, `counter-e` и независимые сдачи
`s17`–`s19`.

`eval`: семейства `sort-b`, `sort-d`, `sort-template`, `counter-f` и независимые
сдачи `s20`–`s22`.

Порог и настройки выбираются только на `setup`, итоговые метрики считаются
только на `eval`.

## Пересборка

```bash
python tools/build_corpus.py
```

Скрипт детерминированно создаёт все файлы корпуса и печатает количество сдач,
записей происхождения и пар.
